# NASA Planets 🌌

Welcome to the **NASA Planets** project! This website is an interactive and educational platform designed to provide fascinating insights about the planets in our solar system. Hosted on GitHub Pages, the site aims to inspire curiosity and learning about space.

## 🌟 Features
- **Informative Content**: Learn about each planet's unique characteristics, including size, distance from the Sun, composition, and more.
- **Interactive Design**: Engaging visuals and user-friendly navigation for an immersive experience.
- **Responsive Layout**: Optimized for viewing on desktops, tablets, and mobile devices.
- **Hosted on GitHub Pages**: Accessible and easy to share.

## 🚀 How to Access
Visit the live website here: [NASA Planets](https://usef304.github.io/NASA-planets)

## 🛠️ Technologies Used
- **HTML5**: Structure and content of the site.
- **CSS3**: Styling and responsive design.
- **JavaScript**: Interactivity and dynamic elements.
- **GitHub Pages**: Hosting the website.
